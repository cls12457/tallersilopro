# Taller de Lógica de Programación (C#)

Tres ejercicios de consola en C#:

- `Ejercicio01_Inventario.cs`: control de inventario de una cafetería universitaria.
- `Ejercicio02_ControlAcademico.cs`: seguimiento de notas de estudiantes.
- `Ejercicio03_Parqueadero.cs`: parqueadero de visitantes.

El enunciado original está en `taller_logica.pdf`.
